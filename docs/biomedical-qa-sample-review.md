日期：2026-10-31。样本文件：[dev_examples.jsonl](../data/biomedical_qa/dev_examples.jsonl)。

## 范围与状态

本批共 22 条中文开发草稿，均来自 P02 一篇论文：15 条可回答、3 条部分可回答、4 条在指定证据范围内不可回答。问题覆盖实验模型、对照、荧光标记、处理条件、方法、实验结果、筛选流程、跨段落比较与证据边界。所有样本属于 `development_draft`，均公开存放，**不是独立验证集或盲测集，也不是可直接使用的 SFT / DPO 数据**。

本次由助手根据 P02 的已索引正文段落逐条完成文本一致性初审，并复核了可定位性、实验条件和不同实验的区分。审核者不具备或声称具备医学专家资质；所有条目的 `review.status` 仍为 `pending_domain_review`，领域审核人和时间均为空。正文中对图表的引用可以辅助回查，但本批标准答案不依赖图像识别或图注；原始数据和图表未逐项审核。

研究原文为 [Tadele 等，P02](https://pmc.ncbi.nlm.nih.gov/articles/PMC7948465/)，正文采用 CC BY 4.0；样本是基于原文编写的中文问题和答案，并非原文逐字摘录。复核版本对应 `sources.json` 的 P02 文件 SHA-256；原文内容或索引版本变化时应重新审核。

## 证据范围与标注约定

- 每题只允许使用 `evidence` 数组列出的段落；包含多个段落时取其并集。`passage_id`、段落位置、原文链接与文件 SHA-256 用于复现。
- `answerable` 表示题目所问内容可从指定范围完整回答；`partially_answerable` 表示至少一项可回答但另一项缺少证据；`unanswerable` 表示关键请求不能在指定范围内确定，也包括不能将体外结果直接外推至患者结局的判断。分类是**相对于指定证据范围**，不代表整篇文献或医学界没有相关信息。
- `required_facts` 供逐点评估；`limits` 列出不能推断的事项。并非逐字匹配标准答案才算正确。涉及数值时必须核对单位、对象、干预、对照和实验阶段。
- 未引用的指定段落不能在人工评分时补充使用，不能将模型已有常识当作来自文献的证据；其他真实知识不等同于已被指定证据支持。
- 当前问答命令按查询检索，不会遵守每题的指定证据范围；在实现范围控制前，**不能直接用现有检索输出评价这些题的范围内答题表现**。应先人工提供指定段落，或后续实现并验证范围过滤。

## 领域审核建议

逐题由熟悉血液肿瘤或相关实验方法的审核者对照论文正文，必要时打开图注、补充材料和原始数据。核实：问题是否无歧义，参考答案与每个必要事实是否被指定段落支持，对照与条件是否准确，证据不足的判断是否限定范围，以及是否需要调整风险标签。数值、单位、实验终点和可能涉及患者用药的条目应优先复核。

审核后在原记录的 `review` 中填写领域审核结果、审核者和日期；有争议的条目先修订并保留 Git 修订记录，再进行第二人复核。不要把助手初审或自动结构校验记作领域审核。修订 `reference_answer`、证据范围或分类后，应同步更新本表并重新做定位校验。
