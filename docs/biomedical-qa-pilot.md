# 医学科研问答试点：伊马替尼与 CML 临床前研究

状态：方案草案。文献档案见 [biomedical-literature-catalog.md](biomedical-literature-catalog.md)，文献登记与待审核开发样本见 [data/biomedical_qa](../data/biomedical_qa/README.md)；已建立两篇文章的本地检索索引，尚未完成模型评估。
目标读者：参与项目设计、数据整理与实验评估的人员。

## 目标与边界

围绕伊马替尼（imatinib，也称 STI571）与慢性髓性白血病（CML）的临床前研究，构建一个基于指定文献回答科研问题的原型。回答须给出可定位的文献证据，区分实验对象、干预条件和观察结果；证据不足时明确说明。

首期聚焦细胞模型中的增殖、凋亡、药物敏感性与耐药相关观察。不以患者诊疗建议或临床疗效判断为目标。细胞实验、动物实验及患者样本的证据层级应明确区分，不能仅凭细胞结果推断患者获益。

初始系统链路：文献整理 → 分段与索引 → 检索证据 → 基础模型生成带引用回答 → 逐例评估。先记录基础模型基线，再在相同评估条件下尝试 SFT；只有偏好数据准备并审核后才进行 DPO。

## 样本与证据设计

每条问答至少保留以下字段；字段名称可在实现时调整，但语义应保持一致。

| 字段 | 内容 |
| --- | --- |
| `id`, `split`, `topic_group` | 样本标识、训练/验证/测试分组、用于隔离的文献或关联研究组 |
| `question`, `question_type`, `language` | 问题、类型与语言 |
| `source_ids`, `evidence` | 文献标识和支持判断的证据位置；每段含版本、章节、段落或图表编号及可定位的片段标识 |
| `reference_answer`, `required_facts` | 经核查的参考回答和必要事实点，包括实验对象、干预及对照 |
| `answerability`, `limits` | 在指定证据范围内是否可回答，以及不能推断的内容 |
| `provenance`, `review` | 文献许可状态、问题编写者、审核者、审核日期和审核状态 |

证据库按论文结构分段，保留来源和位置；图表结果如果无法可靠解析，应标为待人工核查，不把猜测当作原文。问答的证据定位至少精确到章节和段落或图表；答案中的每项实质性事实应对应可检查的引用。

问题类型建议覆盖：实验模型与条件、结果提取、单药与联合处理对比、敏感与耐药模型对比、研究局限、证据不足与不可回答。中文提问与英文文献的对应关系也应纳入检查。

**仅供方案说明的示例，不纳入正式测试集：**

- 问题：P01 中，STI571 单独处理与对照相比，对 K562 细胞增殖和凋亡分别有什么影响？
- 待核查证据：P01 Results 的增殖和凋亡小节及 Fig. 1–2；须同时核对条件、对照组及图注。
- 期望回答要点：描述该论文中单药组的观察，避免将联合干预结果归给单药；说明这是细胞实验，不能单凭该实验推断患者疗效。
- 说明：该问题及要点尚未经过独立专家审核，不视为正式标准答案。

## 划分与防泄漏

1. 先确定关联文献组并固定 train / validation / test，再编写训练数据与偏好对。按论文及关联研究分组；共享数据、实验或高度重复的论文放在同一组。保留分组理由、版本和随机种子。
2. 测试问题、参考答案和人工评分细则中的逐题内容不参与训练、偏好构造、提示词反复调整或模型选择。验证集用于迭代；测试集只在方案锁定后进行最终评估，必要时保留全新测试集。
3. 将**可检索的文献语料**与**问答标签**分开：若测试目标是在已收录文献上回答新问题，可以让系统检索测试论文全文，但不能向训练流程提供测试问题或答案。另设按论文留出的测试切片，检验检索库新增未用于任务微调的论文后的表现。
4. 保存检索索引、模型、提示词和生成配置的版本；对训练/评估样本做精确及近重复检查。基础模型可能在预训练时见过公开文献，不能把项目级隔离称为预训练层面的绝对未见。

## 初期评估方案

目标先人工编写并审核约 20–30 个验证问题和 20–30 个独立测试问题，按上述类型覆盖；这是流程验证目标，不是统计充分性承诺。来源有限或达不到隔离条件时先扩充文献，而不是为了凑数量切分同一研究。记录每类实际样本数；问题和标准答案由熟悉领域的人核对，条件允许时由独立人员复核分歧。

固定同一语料、检索配置、问题、生成参数及评分规则，先比较基础模型与 SFT 模型；DPO 模型满足数据审核条件后再加入。记录模型 revision、硬件、依赖版本、索引、检索结果和原始输出。另做检索是否命中所需证据的检查，避免把检索失败一概归因于生成模型。

逐例记录以下指标，并按问题类型及可回答性分别给出分子、分母和比例；允许标记“不适用”，不把缺失标签记为通过：

- **证据命中率**：需检索证据的问题中，前 k 个检索片段包含人工标注的充分证据的比例，报告 k。
- **事实支持率**：人工拆分可核查的实质性事实，统计被所引证据支持的事实数 / 事实总数，同时单列无引用、错误引用和证据不支持的事实。
- **引用有效率**：可解析且能支持对应陈述的引用数 / 需核查引用总数；另记录没有引用的应引用陈述。
- **要点覆盖率**：回答覆盖且表述正确的必要事实点数 / 该题必要事实点数；注明遗漏实验条件或对照组。
- **证据不足处理**：在人工标注为不可回答或仅可部分回答的题目中，正确指出缺口、未编造缺失结论的比例；在可回答题中另报不必要拒答比例。
- **风险错误**：逐例记录将细胞结果夸大为临床疗效、混淆单药与联合处理、错误实验对象或干预等，报告题数和错误类型。

EM、token F1 和 ROUGE-L 可作为辅助回归指标，不替代事实与证据审核。小样本报告逐例结果及不确定性，不据此宣称模型具备临床可靠性。第三方模型双位置评审可供辅助，须保留原始判决及不一致结果，不替代人工审核。

## 实施顺序与验收

1. **语料准备**：核对许可和来源，确定足够独立的文献组，登记元数据与版本。
2. **评估集准备**：先做少量可追溯样本并审阅，再扩充、分组和锁定测试集。验收：每题有明确证据范围、事实点及审核状态，分组无已知关联泄漏。
3. **基础模型验证**：下载并固定模型版本；先验证本机加载与生成，再接入检索。验收：能回答、显示来源并保存逐例结果；当前尚未完成此验证。
4. **SFT 和 DPO**：只使用允许的训练组；分别保留版本、配置和实验输出，在固定评估上比较。DPO 的 rejected 是候选，不天然低于 chosen，须由审核者基于证据判断。

模型权重、文献原文、派生数据和运行结果在用途、存储与版本管理方案确定前不要直接提交仓库。当前文档不包含训练数据，也不代表系统已经实现。
