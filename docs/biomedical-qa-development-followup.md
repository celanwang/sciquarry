# 医学问答开发基线：调整与回归

日期：2026-10-31。本文对照[首次开发基线](biomedical-qa-development-baseline.md)，结果用于定位工程问题，不是正式医学评测。22 条问题均来自同一篇 P02 文献、未经过领域专家审核，且本轮根据这些开发结果调整了代码，存在开发集适配和过拟合风险。

## 调整内容

1. **检索**：扩充实验、筛选、重复、分化、浓度和阳性对照等试点中英文词汇。仍是基于 BM25 的有限词面匹配，并非语义检索；没有改变索引或自动判定证据质量。
2. **引用编号**：除了已检索与未知的完整编号，还能提示方括号内形似段落编号但格式残缺的引用；如果答案同时包含有效和残缺编号，不再简单标记为全部识别。它不核验事实、不检查未引用事实，也无法识别所有引用格式。
3. **人工复核提示**：对部分数字形式的“生物学重复”陈述添加 `verify_biological_replicate_count` 标记，不自动判断真伪，也不能保证覆盖所有表达。该标记不会阻止或改写模型回答。
4. **提示词试验**：尝试了两版更明确的证据范围与重复次数约束。实际回归中它们未能可靠解决重复次数编造，且出现与原文相反的敏感性比较；两版均未保留。最终版本恢复首次基线的提示词，因此不能声称回答推理能力得到改善。

## 对照方法

沿用同一批 22 题、相同 P02 索引、同一台正在运行的 MLX-LM 服务及本机 Qwen3-4B BF16 权重；生成设置仍为 `temperature=0`、1024 token 上限、关闭思考模式。已核对本机配置、分词器及三个权重分片 SHA-256 与首次基线记录一致；上游模型 commit 未记录。每次运行记录样本、索引和代码摘要。环境指纹与首次基线一致，仍不能保证逐字可重复。

- 首次检索：`data/local/evaluations/retrieval-v1.jsonl`；本轮最终检索：`data/local/evaluations/retrieval-v4.jsonl`。
- 首次回答：`data/local/evaluations/answer-v1.jsonl`；本轮最终回答：`data/local/evaluations/answer-v4.jsonl`。
- 两版被撤回的提示试验输出：`data/local/evaluations/answer-v2.jsonl`、`data/local/evaluations/answer-v3.jsonl`。这些文件及原始模型不进入 Git。

检索使用整个 P02 索引，记录前 3 条是否包含样本标注的证据；回答测试仅提供各题指定的证据段落，不传参考答案。以下对回答的复核由助手完成，未经过领域专家审核，不给出医学正确率。

## 固定证据回答回归

22 题均正常结束。最终输出中，21 题有可识别的已给出引用编号，`015` 的段落编号缺少来源前缀，现被标记为 `malformed_citation`。首次基线将该题标记为 `missing`；两次判定规则不同，这只能说明异常类型现在更清晰，不能解释为引用生成能力改善。

几个有代表性的逐例观察：

- `012`：两版被撤回的提示试验都把 BCR–Abl 细胞与 WT 的敏感性方向说反，甚至与输出中的英文原文自相矛盾；最终恢复原提示后，本次回答方向与证据一致。
- `022`：最终回答仍错误地将阳性对照的 16 个孔当成 16 次独立生物学重复；程序同时给出 `verify_biological_replicate_count`，但答案本身未被修正或阻止。
- `006`：最终回答仍将 mCherry 的中文名称表述错误，说明英文标记保留并不保证解释正确。
- `009`：最终回答仍未明确 72 小时后比例为 1:1 对应 DMSO 条件。
- `018`、`021`：最终回答仍有把指定片段缺失概括为整篇文献缺失的风险。
- `004`、`019`：回答仍存在竞争劣势主体表述不清的问题。

提示词试验虽然让部分条目措辞更接近参考要点，但同时出现更严重的方向性回归；没有足够依据判断哪版在独立问题上更好。最终版本不将其中任何一版作为默认改进。

## 仍需处理

模型答案中的不支持断言、比较方向和证据范围错误仍需人工核对；当前复核提示与引用格式检查不是事实验证。下一步应先补充经领域审核、来自独立文献的开发和测试样本，再评估更稳健的检索方案及独立证据核验；对具体词表和提示词的改动继续保留逐题对照，避免针对已有题目过度拟合。
