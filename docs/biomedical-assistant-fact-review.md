# P02 模型回答：事实断言助手初审

日期：2026-10-31。此文件是对本机 `answer-v4` 生成的 46 个候选片段所做的**助手文本初审**，不是医学领域专家审核，也不是医学事实金标准。每个片段可能包含多个结论；本次拆分出 68 条判断单位，它们有重复和依赖关系，不是 68 个独立题目。

## 范围与方法

- 数据来源为首次开发基线的 22 条公开开发题及 P02 本地证据。完整模型回答和 46 个候选片段保存在 Git 忽略的本机 `data/local/evaluations/`，候选文件为 `claim-review-candidates-v2.jsonl`；它不是独立测试集。
- 每条判断只依据该题**实际提供给模型**的段落；没有以全文其他段落、个人记忆或模型自信度补充证据。阅读范围是正文索引，未独立审核图像或补充材料。
- `指定范围内有依据` 包括原文陈述直接支持，以及“指定片段未给出，因此不能推断”的范围内判断；后者是对所给片段的审阅，不证明全文或现实中不存在该信息。
- `与指定证据相反` 仅在证据直接展示相反事实时使用；`指定证据不足` 表示该范围不能确认，不等于证明断言为假；`超出指定范围` 表示把局部证据扩展为全文或更广泛结论；`需澄清` 用于主体、翻译或原文本身有歧义的情况；`非断言` 用于引导语等。
- 引用编号格式与事实支持分开记录。片段编号有效不代表证据支持，编号有误也不必然意味着事实错误。
- 机器可读的 [逐项记录](../data/biomedical_qa/assistant_fact_review_v1.jsonl) 保存判断、理由、风险标签，以及相对于本机候选文本和证据段落的 Unicode 字符偏移。输入文件 SHA-256 和来源摘要已固定。记录没有包含完整论文原文；换机器时需使用摘要一致的本地候选文件和索引。

- **表述或原文待澄清**：`006:1` 的 mCherry 中文名称异常；`004:2`、`019:2` 的竞争劣势主体不清。`015:3` 所依据原段写保留 13 个化合物，但紧接着的两类数量为 4 和 8，存在待核对的原文内部数目不一致；不应自行修正或直接归咎于模型。
- **引用格式**：`015` 的三个片段引用编号缺少来源前缀，尽管其中部分数字可在指定段落找到依据。
