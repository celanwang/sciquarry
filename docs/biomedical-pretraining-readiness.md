## 进入 SFT 之前尚需完成

1. **可用数据与权限**：核实准备使用的原始文献、问答及研发资料的具体用途、版本和授权；解决 P01 许可表述冲突和 P04 权利不明的问题，不能把这些来源默认纳入训练。
2. **领域审核**：由具备相应专业知识的人员审查问题、答案、引用、实验条件及高风险错误；当前用户表示暂时没有可参与的专家，因此相关状态保持待审核。
3. **数据隔离与去重**：按论文及关联研究、数据源、项目或主题划分训练、验证和独立测试组，审查复用实验、近重复与派生关系，固定版本并保留记录。现有 P02/P05 题均已公开使用，不能作为未公开盲测。
4. **标准数据与基线**：形成经过审核且具溯源的 SFT 样本，以及未用于开发或训练的测试集；先锁定其证据范围、评分准则、模型版本和原始基线。需要同时评估检索、证据支持、风险错误和拒答，词面指标只作辅助。
5. **实验环境确认**：明确 MLX / MLX-LM 的版本、精度、序列长度、训练配置及适配器保存方式，并验证后续环境可复现。SFT 工程链路已实现，并已使用虚构数据完成本机冒烟；尚未完成受审核医学数据上的 SFT。详见 [SFT 说明](biomedical-sft.md)。

## 进入 DPO 之前额外需要

先有已验证的 SFT 策略及其固定版本；在隔离后的训练问题上生成待比较的策略输出，结合可追溯证据准备偏好对，由专业审核者确认优劣及风险并记录来源。模型输出不能因为作为 rejected 候选就自动视为较差回答；评估集不得参与偏好数据构造或选择。还需单独验证所选 MLX 适配器与 DPO 框架的格式及参考策略，不能假设跨框架直接兼容。

本机无法验证 NVIDIA 双卡 DDP、RTX 5090 或 CUDA / FlashInfer 行为；这些属于后续具备相应硬件时的独立实验。已运行的 SFT 限于虚构样本冒烟；没有运行正式医学数据训练、DPO、权重合并或偏好训练。
