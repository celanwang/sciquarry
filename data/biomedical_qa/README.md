# 试点文献与开发样本

- `sources.json`：候选文献来源、许可线索与尚待完成的关联核查。
- `dev_examples.jsonl`：5 条基于 P02 指定证据范围的开发样本草稿，包括可回答、证据边界和不可回答问题。

样本由助手依据文献整理，尚未经过领域专家审核，也没有逐项复核图像原文；不是训练集、验证集或盲测集，不得用于报告医学能力。人工审核时应对照原文与图注，检查每个事实、范围和出处，并填写审核者、日期及审核结果；需要修改时保留修订记录。

当前文件不包含文献全文。P02 和 P03 的页面提供了署名许可线索；在下载、索引、训练或发布相关内容前，仍须检查具体用途、署名义务及第三方材料。P01 和 P04 的许可尚未确认。候选分组尚未锁定；不要从这些开发样本派生测试题。
